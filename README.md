# TriageLab demo

This repository exists to demonstrate [TriageLab](https://github.com/bondrenai/TriageLab)
picking up a labelled GitHub issue and investigating it in a sandbox.

The issue here is fiction written for the demo: the customer (Larkspur
Wholesale), the people, the `rowferry` sync tool and its order data do not
exist. The code and data attached to the issue are real enough to run, and
TriageLab's investigation of it is a real run.

The case comes from
[`examples/missing-orders`](https://github.com/bondrenai/TriageLab/tree/main/examples/missing-orders)
in the TriageLab repository.
